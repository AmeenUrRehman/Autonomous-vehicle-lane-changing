How the MPC Loop Works
1
Read state: current v_y, psi, r, Y, and previous steering.
2
Predict: build future outputs over the selected horizon.
3
Optimize: minimize tracking error plus steering increment effort.
4
Apply: use only the first steering move, then repeat.
